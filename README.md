# Sachu S - Professional Portfolio

Welcome to the source code for my fully responsive, animation-rich personal portfolio website. Built to showcase my 5+ years of experience as a Software Engineer & Technical Lead specializing in Python, Django, FastAPI, and enterprise healthcare solutions.

## 🚀 Live Demo
[View Live Portfolio](https://sachusudevan.github.io/portfolio/) *(Update link once GitHub Pages is configured)*

## ✨ Key Features
- **Premium Dark Mode Design**: Sleek aesthetics with glassmorphism panels, deep backgrounds, and glowing accents.
- **Advanced Animations**: Leveraging AOS for scroll reveals and custom JavaScript typing effects.
- **Interactive UI/UX**: Custom cursor, micro-interactions on hover, and smooth scrolling navigation.
- **Fully Responsive**: Mobile-first architecture ensures a seamless experience on all devices.
- **Dynamic Projects Section**: Filterable portfolio projects showcasing Healthcare, Enterprise, and E-commerce work.

## 🛠️ Built With
- HTML5 (Semantic Structure)
- CSS3 (Variables, Flexbox, Grid, Keyframes, Custom Properties)
- Vanilla JavaScript (DOM manipulation, Custom event handling)
- FontAwesome (Icons)
- Google Fonts (Inter & Outfit)

## ⚙️ Local Setup
1. Clone the repository: `git clone https://github.com/sachusudevan/portfolio.git`
2. Navigate to the directory: `cd portfolio`
3. Open `index.html` in your favorite web browser or use a local server like Live Server (VS Code).

## 🌍 GitHub Pages Deployment
1. Push the code to a new repository named `portfolio`.
2. Go to Repository **Settings** > **Pages**.
3. Under **Source**, select the `main` branch.
4. Save, and your portfolio will be live at `https://[username].github.io/portfolio/`.
